# Contributing to VOLT

Thank you for your interest in contributing to VOLT!

## Code of Conduct
Please be respectful and constructive in all discussions, issues, and pull requests.

## How to Contribute
1. **Report Bugs**: Open an issue describing the bug, steps to reproduce, and your environment.
2. **Suggest Enhancements**: Open an issue describing your proposed feature or improvement.
3. **Submit Pull Requests**:
   - Fork the repository.
   - Create a feature branch: `git checkout -b feature/my-feature`.
   - Make your changes and write tests where applicable.
   - Ensure the code formats properly: `cargo fmt`.
   - Run tests: `cargo test`.
   - Commit your changes with clear commit messages.
   - Push to your fork and submit a Pull Request.
